# プロフィール兼ホーム

Issue #63。ログイン後のトップをプロフィールと利用実績の画面に変更。
新規チャットは /new、会話は従来の /c/:id。ホームからプロジェクトや最近の会話を開ける。

GET /api/usage はセッションの所有者の保存済み完了回答を集計する。入出力トークンと
費用記録が揃ったassistant行が対象。アーカイブも含む。分岐コピーは使用量を持たない。
累計と最大は保存期間全体。ヒートマップは今日を含む365日、日本時間。
週別は月曜始まり。累計表示は期間開始前の利用を含む。連続利用は表示期間内で計算する。現在の連続利用は今日または
昨日まで連続した活動日。結果に会話本文・タイトル・請求額を含めない。

ユーザー名とイニシャルを表示。利用履歴がない場合は0を表示し、集計エラーとは区別する。
プレビューは合成利用履歴を使う。実環境の画面は同じAPIから本人の実績を表示する。

検証はローカル186件成功、PostgreSQL依存35件はCIで実行。型検査、ビルド、整形、
依存関係監査成功。ブラウザーでLight/Dark、320〜1440pxの7サイズ、日別・週別・累計、
新規チャットとホームの往復を確認。証跡は evidence/profile-home/。

統合順は #62 → #64 → 本PR。DB移行なし。Rollbackは本PRのrevert。
本番反映は統合後のCI・レビューと承認を経て実施する。
